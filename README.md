# SupportOps

SupportOps is a cloud-based IT support and incident management platform designed to help support teams manage tickets, incidents, users, and service issues.

## Project Goals

- Manage and track support tickets
- Track incidents and their resolution
- Implement role-based access
- Monitor application health and performance
- Deploy a production-style application using AWS
- Practice Docker, Terraform, CI/CD, and cloud infrastructure

## Planned Technology Stack

- React
- Node.js
- Express
- PostgreSQL
- Docker
- AWS
- Terraform
- GitHub Actions

## Project Status

Currently in development.

The project will be built incrementally, starting with the application foundation and eventually progressing to cloud deployment, infrastructure as code, CI/CD, monitoring, and incident response.
